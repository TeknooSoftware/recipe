# Security Policy

## Supported Versions

The following versions of this library currently receive security updates :

| Version | Supported          |
|---------|--------------------|
| 7.x.x   | :white_check_mark: |
| < 7.x.x | :x:                |

## Reporting a Vulnerability

Basically, send an email to `richard@teknoo.software` with the vulnerability description and a proof of concept of
the exploit. Please do not open a public issue for a vulnerability.
This is a free project, written on my free time, so: there are no bug bounty, but you will be credited in the
version's description, changelog and the contributors list.

Thanks
